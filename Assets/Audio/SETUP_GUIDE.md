# Free Audio Resources for Wizard Lizard

## 🎵 Quick Start - Free Downloads

### 1. Freesound.org (Free with account)
**Direct links for game-ready sounds:**

**Player Sounds:**
- Footsteps: https://freesound.org/search/?q=footstep+stone
- Running: https://freesound.org/search/?q=running+footsteps  
- Magic Hide: https://freesound.org/search/?q=magic+whoosh

**Environment Sounds:**
- Key Pickup: https://freesound.org/search/?q=key+pickup
- Treasure: https://freesound.org/search/?q=coins+pickup
- Door Open: https://freesound.org/search/?q=door+creak

**Enemy Sounds:**
- Alert: https://freesound.org/search/?q=monster+growl
- Chase: https://freesound.org/search/?q=evil+laugh

**Background Music:**
- Ambient: https://freesound.org/search/?q=dungeon+ambient
- Fantasy: https://freesound.org/search/?q=medieval+background

### 2. Unity Asset Store (Free Packs)
- Search "Free Audio" in Unity Asset Store
- Download "Free SFX Package" 
- Import directly into your project

### 3. Quick Test Files
You can also use any .wav, .mp3, or .ogg files you have on your computer for testing!

## 📁 Where to Put Audio Files

1. Download audio files to your computer
2. In Unity Project window, navigate to: Assets > Audio > Music (or SFX)
3. Drag and drop audio files from your computer into Unity
4. Unity will automatically import them

## 🔧 Example Setup

After importing audio files:
1. Select AudioManager GameObject in Hierarchy
2. In Inspector, you'll see AudioManager component
3. Drag audio files from Project window to the audio slots
4. Set volume levels (0.5 is usually good)
5. Press Play to test!
