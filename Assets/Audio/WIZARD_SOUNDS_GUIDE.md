## 🔧 UNITY AUDIO SETTINGS:

For each sound file in Unity:
- **Compression Format**: Vorbis (for most sounds)
- **Quality**: 70% (good balance)
- **Load Type**: "Decompress On Load" (for short sounds)
- **Load Type**: "Streaming" (for long background music)
